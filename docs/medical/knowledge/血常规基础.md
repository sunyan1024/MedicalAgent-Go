# 血常规（CBC）基础

来源机构：美国国家医学图书馆 MedlinePlus。
来源：https://medlineplus.gov/lab-tests/complete-blood-count-cbc/
原文发布日期：未核实，不以检索日期代替。
摘要整理日期：2026-09-11。
用途：求职 Demo 的人工整理科普摘要，不是临床指南。

血常规是一组检查血细胞数量、大小等信息的检测，涉及红细胞、白细胞、血小板、血红蛋白、红细胞比容和平均红细胞体积（MCV）。红细胞及其中的血红蛋白参与氧的运输，白细胞参与对抗感染等过程，血小板参与凝血。

CBC 可用于常规健康检查，也可用于观察影响血细胞计数的疾病或治疗。单个异常指标不能独立说明具体病因，医生需要结合其他信息判断。本文不提供统一正常值，也不提供个体诊断、治疗或处方。
